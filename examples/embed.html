Embedding CS Viewer

Two ways to put a third-person replay on a page. Both need the game assets served somewhere (maps/ and models/) — see the README.

1. No JavaScript — just markup

Give an element data-cs-viewer, point it at a demo, and call autoMount() once. 

<div data-cs-viewer
     data-demo="/demos/demo.dem"
     data-assets="/assets"
     style="height: 540px"></div>

<script type="module">
  import { autoMount } from '/dist-lib/cs-viewer.js'
  autoMount()
</script>

2. With the API

createCsViewer returns a handle you can drive from your own controls — useful for linking a replay to a timeline, a scoreboard or an article. 

import { createCsViewer } from '/dist-lib/cs-viewer.js'

const viewer = createCsViewer('#replay', {
  demo: '/demos/demo.dem',
  assets: '/assets',
  mode: 'third-person',
  controls: false,     // drive it yourself
  roster: false
})

viewer.on('ready', (match) => console.log(match.mapName, match.players))
viewer.seek(1200)
viewer.follow(5)
